FAQ

常见问题

天空影视提供在线播放吗？

不提供。本站仅整理影视作品的名称、类型、主创与上映信息，并给出正版观看渠道的跳转链接，不涉及任何资源的存储与分发。

网址为什么是 github.io 结尾？

本站托管在 GitHub Pages 静态托管服务上，因此访问地址为 https://tiankongyingshi-zh.github.io，全程 HTTPS 加密，页面加载不依赖外部脚本。

片单多久更新一次？

精选片单每周更新一次，口碑排行每月初按编辑评分与观众反馈重新排序，更新记录可在「关于本站」的版本日志中查看。

条目信息有误怎么办？

影视条目中的年份、集数、类型等以片方与发行方公开信息为准。如发现明显错误，可通过页面底部的联系邮箱反馈，我们会在两个工作日内核对修正。

为什么有些影片找不到观看渠道？

部分独立电影、纪录片与海外作品尚未在本地平台上线，这类条目只保留基本信息与上映状态，不添加任何观看链接，避免指向不明来源。

页面在手机上显示正常吗？

正常。本站采用响应式布局，从 360px 宽的手机到桌面显示器都会自动调整栏数与字号，窄屏下导航会收起为侧边菜单。
